## 📊 Featured Project

### 🍽️ Zomato Restaurant Data Analysis and Dashboard

[![Zomato Repository](https://img.shields.io/badge/View_Project-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/Vandy2004/zomato-data-analysis)

An exploratory data analysis project focused on restaurant trends, customer preferences, ratings, online ordering, and pricing patterns using the Zomato restaurant dataset.

**Technologies Used**

Python · Pandas · NumPy · Matplotlib · Seaborn · Streamlit · Plotly

**Key Highlights**

- Performed exploratory data analysis on restaurant data.
- Examined restaurant locations, cuisines, ratings, votes, online ordering, table booking, and cost for two.
- Visualized rating distributions, popular cuisines, restaurant counts, and cost-rating relationships.
- Identified BTM Layout as the area with the highest restaurant count in the analyzed dataset.
- Found that approximately 58.87% of restaurants offered online ordering in the analyzed dataset.
- Developed an interactive Streamlit dashboard to communicate findings visually.

**Repository Contents**

- `Zomato Analysis (1).ipynb` — Jupyter Notebook for data analysis
- `Zomato Analysis (1).html` — HTML export of the analysis
- `app.py` — Streamlit dashboard application
- `zomato.csv` — Dataset
- `requirements.txt` — Python dependencies
